# TypeScript exercises

This directory contains the TypeScript tasks for the Holberton School Web React
project. Each task is an independent webpack project in `task_0` through
`task_5`.

From a task directory, install the dependencies and run the development build:

```sh
npm install
npm run build
```

Task 3 exercises ambient declarations and CRUD imports. Task 4 demonstrates
namespaces and declaration merging. Task 5 demonstrates branded credit types.
